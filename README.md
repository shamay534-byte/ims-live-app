# מפות מודלים – ECMWF · ICON שמ״ט · COSMO שמ״ט

אפליקציית צפייה במפות תחזית בסגנון Windy: מפה כהה, שדה צבעוני חלק, חלקיקי רוח מונפשים,
ציר זמן לדפדוף ואנימציה, בחירת פרמטר ושכבת גובה, ונקודת דגימה עם גרף לאורך הריצה.

## מקורות הנתונים

| מודל | מקור | מה מוצג |
|---|---|---|
| **ECMWF IFS HRES** | [ECMWF Open Data](https://data.ecmwf.int/forecasts/) – קובצי GRIB2 ברזולוציה **0.1°** (~9 ק״מ, הרזולוציה הגבוהה ביותר בנתונים הפתוחים), רישיון CC-BY-4.0 | נתונים גולמיים שמעובדים ומצוירים בדפדפן: טמפרטורה, רוח, משבים, משקעים, עננות, לחות, לחץ/גובה גאופוטנציאלי, CAPE · קרקע + 925/850/700/500/300/250 hPa · עד 360 ש׳ |
| **ICON-IL (שמ״ט)** | [מפות המודלים באתר השירות המטאורולוגי](https://ims.gov.il/he/ModelMaps) | המפות המוכנות שהשירות מפרסם (כל 3 ש׳ עד 90 ש׳, אזורים: ישראל וסביבתה, מזרח הים התיכון, דרום-מזרח אירופה, הבלקן) |
| **COSMO-IL (שמ״ט)** | כנ״ל | כנ״ל (ישראל וסביבתה, מזרח הים התיכון) |

> קובצי ה-GRIB של ICON-IL ו-COSMO-IL אינם מפורסמים לציבור (פורטל הנתונים של שמ״ט דורש הרשאה),
> ולכן עבור מודלים אלה מוצגות המפות הרשמיות של השירות. אם תתקבל גישה ל-GRIB, אפשר להוסיף אותם
> לאותו צינור עיבוד של ECMWF ולקבל עבורם את אותה תצוגה אינטראקטיבית.

## איך זה עובד

```
scripts/ecmwf_fetch.py   מוצא את הריצה האחרונה (00Z/12Z) שהושלמה, מוריד רק את השדות הדרושים
                         (HTTP Range לפי קובצי ה-.index), מפענח GRIB2 עם ecCodes, חותך לתיבה
                         27–37.5°N, 27–42°E ושומר כ-int16  →  public/data/ecmwf/
scripts/ims_manifest.py  מוריד את קטלוג המפות של שמ״ט (ה-API שלהם לא מאפשר CORS)  →  public/data/ims/
app/ + components/       Next.js (ייצוא סטטי) + MapLibre: השדה נצבע ל-canvas בהטלת מרקטור,
                         חלקיקי רוח וקווי שווה לחץ/גובה מצוירים בשכבות-על
.github/workflows/       כל 3 שעות: רענון נתונים, בנייה ופרסום ל-GitHub Pages
```

## הרצה מקומית

```bash
npm install
pip install -r scripts/requirements.txt
npm run data:ims                                    # קטלוג המפות של שמ״ט (שניות)
python3 scripts/ecmwf_fetch.py --max-step 48        # ECMWF עד +48 ש׳ (דקה-שתיים); בלי הדגל: עד +360
npm run dev                                          # http://localhost:3000
```

## פרסום (GitHub Pages)

1. ב-GitHub: **Settings → Pages → Source: GitHub Actions**.
2. למזג ל-`main`. ה-workflow ירוץ בכל push ל-`main`, כל 3 שעות, ובאופן ידני (Actions → Run workflow).
3. האתר יעלה בכתובת `https://<user>.github.io/ims-live-app/`.

## שימוש

- **לחיצה על המפה** – מזיזה את נקודת הדגימה (ערך + גרף לאורך כל הריצה). חיפוש יישוב בשורה העליונה.
- **ציר הזמן** – לחיצה/גרירה, החצים, או מקשי ← → במקלדת; רווח = הפעלה/עצירה.
- **החלפת מודל** שומרת את שעת התחזית ומתאימה את סוג המפה הקרוב ביותר.
- הקישור בשורת הכתובת משקף את התצוגה (מודל, פרמטר, גובה, שעה) – אפשר לשתף אותו.
